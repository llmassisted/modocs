Synthetic, non-sensitive regression documents generated for MoDocs.

- preservation.docx: mixed formatting, hyperlink, header relationship, custom paper size and a complex read-only field paragraph.
- preservation.xlsx: frozen row/column, merged title, cached formula, data validation, conditional formatting, and a distant search result.
- partial.pptx: one malformed slide and one readable slide, to verify recovery notices.
- PDF cases are generated in DocumentRegressionTest: searchable text, rotated/cropped pages and AcroForm fields.

Run `./gradlew :app:connectedDebugAndroidTest`. Never replace these with private user documents.
